# キャンバスと表編集の試作

## 目的と構成

日本語入力、表計算ソフトからの貼り付け、拡大縮小した状態での編集、表とキャンバスの操作の競合を確認するための試作。製品の初期目標すべてを実装した段階ではない。

- 画面: React / TypeScript、React Flow、Vite。
- 表: HTML の table と textarea。IME を標準入力欄で扱う方式から検証し、Glide Data Grid の採否は保留する。
- 中核: Rust。表の更新、配置、Undo / Redo を共通操作で処理する。
- 接続: 試作用の axum HTTP アダプタ。Vite からローカルの Rust コアへプロキシする。
- 状態: Rust プロセスのメモリ内。終了前に [プロジェクトファイル](project-files.md) へ保存すると、再起動後に読み込める。自動保存はない。

Tauri の WebView への組み込みは未実施。ブラウザでの確認結果が、そのまま macOS WebView の IME 挙動を保証するわけではない。

## 起動とコードの配置

[ルート README](../README.md) の手順で起動する。

| 場所 | 担当 |
| --- | --- |
| `src/app/` | 全体画面、プロジェクトの表示状態、操作キュー |
| `src/features/canvas/` | 表ノードの表示・サイズ変更 |
| `src/features/table/` | セル入力、範囲選択、行の部分描画、TSV 変換 |
| `src/api/` | Rust への要求と応答の検証 |
| `backend/src/domain.rs` | 試作の表と操作の型 |
| `backend/src/application.rs` | 検証、一括編集、配置、Undo / Redo |
| `backend/src/main.rs` | ローカル HTTP アダプタ |
| `scripts/dev.mjs` | 開発用プロセスの起動・停止 |

これは Tauri 採用時の配置例とは異なる試作用構成。中核に UI ライブラリへの依存は持たせていない。

## 操作

| 操作 | 方法 |
| --- | --- |
| セル編集 | セルをクリックして入力。フォーカスを離すと Rust 側へ反映 |
| セル移動 | Tab / Shift＋Tab で左右、Enter / Shift＋Enter で上下 |
| 変換確定 | IME 変換中の Enter はセル移動に使わない |
| セル内改行 | Option＋Enter |
| 入力取消 | Escape でそのセルの編集前の値に戻す |
| 複数セル貼り付け | 起点のセルを選び、TSV を貼り付ける。足りない行列は自動追加 |
| 範囲選択 | 最初のセルをクリックし、最後のセルを Shift＋クリック |
| 範囲コピー | 範囲選択後に ⌘C。単一セルは入力欄の文字選択を使う |
| タイトル変更 | タイトル横の鉛筆ボタン、またはタイトルをダブルクリック。Enter／フォーカス移動で確定、Escape で取消。日本語 IME の変換確定 Enter は編集終了に使わない |
| 表の削除 | 表内の赤系の「削除」ボタン。接続も外れる。Undo で内容と接続を復元。最後の1ノードは削除不可 |
| 表の移動 | 表の見出しをドラッグ。画面端での自動パンは行わず、一度に一つの表を移動 |
| 表のサイズ変更 | 表を選択し、枠の端や角をドラッグ |
| 表内スクロール | 表の内側でスクロール。キャンバスのパンとは分離 |
| キャンバス移動 | 余白をドラッグ、または余白でスクロール |
| ズーム | ピンチ、右下の＋／−。倍率をクリックすると 100% に戻る |
| Undo / Redo | 左上の操作ボタン。最大30件の変更前状態を保持 |

入力欄での ⌘Z はブラウザのテキスト編集として扱い、プロジェクト全体の Undo はボタンで行う。

## 制限

- セルはすべて文字列。型指定、列名変更、行列削除は未実装。
- 上限は試作の保護用として 1 表5000行・50列、合計20ノード、1セル100 KB、HTTP 要求16 MiB。製品としての容量目標ではない。
- 画面に近い行だけを描画する。編集中の行は画面外でも保持し、スクロールで変換中の文字を失わないようにする。
- 表 ID は安定しているが、行列は位置指定。製品版の行・列 ID は未実装。
- GUI の要求はタブ内で順番に実行し、SSE で別タブへ変更を通知する。詳細は [別タブ間の同期](tab-sync.md) を参照。
- 操作失敗時は入力内容を保持して再適用・破棄を選ぶ。セルの比較条件で同じセルへの意図しない上書きを防ぐ。
- ページを閉じる際に未書き出しの変更・未確定入力への警告を要求する。警告を無視して閉じると未確定入力は失われる。
- [フィルタフロー](filter-flow.md) と接続・設定・キャッシュの保存を追加済み。外部スクリプト、MCP は未実装。

## 検証記録

2026-11-22、macOS 上のローカル試作で確認。

### 自動検査

- TypeScript 型検査と Vite ビルド。
- Vitest: TSV の日本語・空セル・改行・引用符、変換中の Enter 抑止、入力途中の保護、編集行の部分描画からの保護、貼り付け起点。
- Rust: 貼り付けによる行列拡張と一操作での Undo / Redo、不正な入力・古い revision の拒否。
- rustfmt / Prettier、Clippy。

ビルドには依存ライブラリ由来の `use no memo` と、500 KB 超のチャンクに関する警告が残る。型検査・ビルドは成功している。

### ブラウザで確認済み

- 日本語を含む2行4列の貼り付けと、一操作での Undo / Redo。
- 70%・150% 表示での日本語文字入力と Tab 移動。
- 見出しによる表の移動、枠からのサイズ変更と Rust 側への反映。
- 二つ目の表への1000行4列の貼り付け、表内スクロール。
- 表内スクロールでキャンバスの位置が変わらないこと。
- Shift＋クリックで選択した2行2列を TSV としてコピーできること。

### 表の移動に関する修正

表を動かすと別の表が遠くへ移動して見える問題への対策として、ノードのドラッグ時の自動パンを無効にした。キャンバス自体は余白のドラッグで移動する。

配置の同期はノードごとに管理し、ドラッグ・サイズ変更中、またはコアへの反映待ちの配置を、古い全体スナップショットで巻き戻さないようにした。複数ノードの同時選択移動は無効とし、表内の Shift＋クリックによるセル範囲選択は維持する。

- 回帰テスト: 表1の応答到着時に表2の反映待ち配置を保持、操作中の配置・測定情報を保持、確定後の Undo 配置を受け入れる。
- ブラウザ確認: 80% 表示で表1を画面上端まで移動しても表2の位置とキャンバスの変換が変わらないこと、および表2の移動時に表1が動かないこと。

### 人間による追加確認が必要

- macOS の日本語 IME の実際の変換候補ウィンドウ、再変換、確定・取消。自動テストは composition イベントを模擬し、ブラウザ操作では日本語文字の入力を確認したが、実 IME の候補選択は未確認。
- 使っているトラックパッドによるピンチの操作感。
- Numbers / Excel からの直接コピー＆ペースト。現時点は同形式の TSV をクリップボード経由で確認。
- Tauri の macOS WebView と Windows での動作。

まず「とうきょう」などを変換し、Enter で確定しても同じセルに留まること、もう一度 Enter で次の行へ移ることを確認する。その後70%・150%表示でも同じ操作を試す。

タイトル変更は入力・フィルタ・結果表で共通。接続は ID で維持し、保存・Undo / Redo・別タブ同期に反映する。空欄と1024バイト超は拒否し、同じタイトルの競合時は未反映の操作として入力を保持する。

## 行削除・列編集

- 手入力表の行（行番号またはセル）を右クリックし、コンテキストメニューの「行N を削除」で削除する。メニューは外側のクリック・Escape・スクロールで閉じる。最後の1行は残す。
- 列名をダブルクリックすると編集欄に切り替わる。キーボードでは列名にフォーカスして Enter / F2 でも編集できる。Enter またはフォーカス移動で確定、Escape で取り消す。日本語入力はセルと同じ変換中の確定防止を使う。列の追加は既存の「＋列」、削除は列見出しを右クリックして「「列名」列を削除」を選ぶ。最後の1列は残す。
- 各操作は共通 API を通し、Undo / Redo・保存・別タブ同期の対象。削除時は表示時の表内容を照合し、途中に別の編集があった場合は拒否する。表示を確認して削除し直す。
- フィルタが参照中の列は削除できない。対象列の変更または切断後に削除する。他の列を削除した場合は、後続フィルタの列番号を補正する。
- 接続先に手動更新・更新待ち・エラーのノードがある場合、旧キャッシュの列構成を誤って解釈しないよう列削除を止める。自動更新に切り替えて更新待ち・エラーを解消するか、接続を外してから削除する。
- 結果表は引き続き読み取り専用。行・列の複数選択削除、列の並べ替えや型変更は未実装。
