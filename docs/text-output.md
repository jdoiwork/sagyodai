# 結果テキスト

ツールバーの「出力を追加」→「結果テキスト」から追加し、入力端子または「入力元」で表・メモ・テキスト入力・加工ノードに接続する。

- 読み取り専用で、各行を改行、複数列のセルをタブでつないで表示する。列名は含めない。空セル・空行も保持し、セル内の改行はそのまま表示する。CSVやTSVのエスケープ処理は行わない。
- 初期表示は「テキスト」。Markdown表示へ切り替えられ、表示形式はプロジェクトに保存・復元される。
- 既定では入力変更に追従する。「手動更新」で前回の結果を保持し、「今すぐ更新」で反映する。上流の失敗時も前回の成功結果を保持する。
- 出力端子は入力表をそのまま後続へ渡す。表示形式やテキストの組み立ては出力の列・行を変更しない。
- 配置・接続・表示形式・出力キャッシュを保存する。コンパクト表示、端子位置・色、別シートへの移動、Undo / Redoにも対応する。

列の選択や順序・列名の変更が必要な場合は、手前に結果表を接続して設定する。区切り文字の指定、クリップボード用ボタン、ファイル書き出しは未実装。
