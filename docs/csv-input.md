# CSV入力ノード

ツールバーの「CSV」で入力ノードを追加し、「CSVを選択」からファイルを読み込む。出力端子をフィルタ・ソート・結合・集計・結果表へ接続できる。CSVノード内の表は読み取り専用で、クイック検索・列の表示絞り込み・表示ソートは出力に影響しない。

- UTF-8（BOM付きも可）、カンマ区切りに対応する。Shift_JIS・UTF-16・区切り文字の選択は未対応。
- 初期設定は「1行目を列名として使う」。チェックを外して読み込むと、先頭行もデータに含め、列名を「列1」「列2」…とする。この選択は次のファイル読込時に適用される。
- 列名の前後の空白を取り、空の列名には「列N」を付ける。重複する名前には「 (2)」などを付けて区別する。
- セルの値は文字列として保持し、先頭ゼロや前後の空白を変えない。引用符内のカンマ・改行・二重引用符に対応する。
- 解析にはRustの[csv crate](https://docs.rs/csv/latest/csv/struct.ReaderBuilder.html)を使用。空行は無視し、行ごとの列数不一致は拒否する。引用符の不正をすべて厳密に検出する方式ではなく、同ライブラリの解析規則に従う。
- 最大1 MiB・データ5000行・50列。列名1000バイト・セル100000バイトまで。列名だけでデータ0行のCSVも読み込める。空のファイルは拒否する。

## 再読込と保存

「CSVを選び直す」から同じファイルまたは別ファイルを読み込む。ファイルパスは保持せず、ディスク上の変更監視・自動再読込は行わない。読み込み成功時に後続を自動更新し、手動更新のノードでは前回の結果を保持して更新待ちにする。CSVノード自体に自動／手動更新の切替はない。

読み込みは共通の `importCsv` 操作でRust側が検証・解析・確定する。容量・文字コード・列数などのエラーはノードに表示し、以前の成功した表を維持する。入力エラーを「未反映の操作」として再送し続けず、ファイルを選び直して修正できる。

ファイル名・ヘッダーの有無・読み込み済みの列名と全行をプロジェクトに保存する。生のCSVファイルや絶対パスは保存しない。自動保存・手動書き出し・Undo／Redo・別タブ同期の対象。元ファイルがなくても保存済みの表から再開できる。プロジェクト全体の8 MiB上限は引き続き適用する。

再読込で列構成が変わった場合、CSVノードの表示条件と列幅はリセットする。後続の列指定は現状の位置参照なので、列構成を変えて読み込み直す場合はフィルタ・集計等の対象列を確認する。結果表の出力列設定は入力スキーマが変わるとエラーとなり、以前の成功結果を保持する。

## 検証

自動テストで日本語・BOM・改行・引用符・先頭ゼロ、ヘッダーなし、空／重複列名、0行、容量・行列数・セル長の制限、失敗時の出力維持、フィルタ伝播、手動キャッシュ、Undo／Redo、保存復元、古いrevisionの拒否を確認。画面のテストでは文字コード・容量・サーバーエラーと修正後の再選択を確認する。

実画面でファイル選択、CSV → フィルタ → 結果表、列数不一致・Shift_JISのエラーと選び直しを確認。独立環境を再起動し、CSVを含む全ノードとrevisionが保存前と一致することを確認した。OSのIME候補選択とWindowsの実操作は未検証。
