# 結果ツリー

「出力を追加」→「結果ツリー」で追加する。メモ、テキストファイル、フィルタや置換の出力など、JSONテキストを含む1列の表を接続する。各行を改行でつないだ全体を一つのJSONとして解析する。複数列の入力は、手前の結果表で1列に絞る。

- オブジェクトのキー、配列の添字、文字列・数値・真偽値・nullを表示する。オブジェクトと配列はクリックで開閉できる。ルートは最初から展開する。
- 大きな配列・オブジェクトは100項目ずつ「さらに表示」で展開する。閉じた枝の子は描画しない。
- 自動／手動更新、今すぐ更新、コンパクト表示、別シート参照、端子の色・位置に対応する。
- JSONの構文エラーや複数列の入力はノード内にエラー表示し、前回成功した出力を保持する。入力を修正すると自動更新で復帰する（手動ノードは今すぐ更新）。
- 配置・接続・更新設定・最後に成功した出力はプロジェクトに保存する。枝の開閉・表示件数は画面内の一時状態で、本文更新時にリセットする。
- 出力端子は検証に成功した元の1列表を渡す。ツリーから値の編集はできない。

JSON Lines、コメント付きJSON、末尾カンマは非対応。深いネストなどJSONパーサーの上限を超えた入力もエラーになる。数値のツリー表示はJavaScriptの数値精度に従う（原文・出力表は文字列のまま保持する）。
