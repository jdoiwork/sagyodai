# メモノード

ツールバーの「メモ」で、キャンバスに注釈を追加する。出力端子からフィルター・置換・結果表などに接続できる。入力端子は持たない。

- 出力は列名「本文」の1列。保存済みの本文を改行（LF／CRLF）ごとに別の行へ分ける。途中の空行・末尾の改行後の空行も保持し、空の本文は空文字の1行を出力する。Markdown記法は原文のままで、HTMLへの変換は行わない。
- 本文を保存すると後続の自動更新ノードへ反映する。手動更新ノードは更新待ちとなり、実行するまで前回の結果を保持する。編集中の未保存本文は出力しない。出力端子の位置・色は他のノードと同様に設定できる。
- 新しいメモは編集モードで開く。本文は通常のテキスト入力・改行・貼り付けができる。
- 「保存して閲覧」で本文を確定し、Markdown表示へ切り替える。「編集」で再編集でき、「キャンセル」で下書きを破棄する。
- 見出し・強調・箇条書き・引用・リンク・画像・コードブロックに加え、表・取り消し線・タスクリストに対応する。HTMLの埋め込みは表示しない。リンクは別タブで開く。
- 本文は100000バイト・5000行（空行を含む）まで。上限超過は編集画面に表示し、保存できない。
- 保存した本文・タイトル・配置・サイズ・所属シートはプロジェクトに保存され、自動保存・復元・別タブ同期・Undo／Redoの対象になる。編集中の未保存本文と編集／閲覧の切り替えはタブ内の一時状態で、再起動時は本文があれば閲覧モードになる。
- 別タブから本文が変わっても編集中の下書きは保持する。保存時には元の本文を照合し、競合した場合は未反映の操作として再適用・破棄を選ぶ。
- タイトルの変更、ノードの移動・サイズ変更・削除、「…」から別シートへの移動に対応する。

描画にはreact-markdownとremark-gfmを使用し、HTMLを実行する変換処理は使わない。
