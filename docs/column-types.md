# 列の型と空欄

2026-11-25追加。手入力の列ヘッダーにある型名から設定する。読み込み済みの表は「加工を追加 → 型変換」を接続して設定する。

## 型と入力

| 型 | 入力 | 空欄の初期値 |
| --- | --- | --- |
| 文字列 | 原文をそのまま保持。`00123`も変えない | 空文字 |
| 整数 | 符号付き64ビット（-9223372036854775808〜9223372036854775807）。前後の空白と先頭の`+`を許可 | `0` |
| 真偽値 | `true`または`false`。前後の空白を許可 | `false` |

小数型、日付・日時型は未対応。整数には小数・指数表記を受け付けない。整数値はRustのi64で扱い、GUI・MCP・型付きJSONLには十進文字列で渡すため、JavaScriptの安全な整数範囲を超えても丸めない。

列ごとに以下を独立して指定する。

- **null許容**：初期値はオフ。型を変更すると新しい型の初期設定に戻る。
- **空欄の扱い**：「指定値」「入力エラー」「null」。nullは許容をオンにした場合だけ選べる。
- **空欄の代替値**：型に合った値を指定する。空欄は長さ0の原文を指し、空白のみの文字列とは区別する。

空欄の代替値はプレースホルダーで表示し、原文の空文字を値で上書きしない。型変更・空欄設定・貼り付け・セル編集はUndo、自動保存、SSE同期の対象。文字列`null`はnull値とは異なる。手入力でnullを作る場合は、その列で空欄をnullに設定する。空欄の規則と別に個別セルへnullを入力する操作は未実装。

## 原文・エラー・成功結果

手入力の`rows`は原文。型に合わない入力も確定・保存し、`cellErrors`で位置と理由を返す。画面ではセルの色とツールチップ、および表上部のエラーで示す。

成功した型付きデータは`output`に保持する。型エラーが1つでもあれば新しい成功結果を確定せず、前回の結果を保持する。後続にも更新待ちを伝え、手動ノードのキャッシュを自動更新しない。成功結果がない場合は`output: null`。整数列のフッターも型エラーを暗黙に除外せず「型エラー」と表示する。

型変換ノードも入力原本を変えない。既存nullをnull非許容の列へ変換するとエラーになる。空欄の代替値はnullの暗黙の置換には使用しない。

## 加工と列ID

`columnSchema`は列ID・名前・型・null許容・空欄規則を持つ。設定UIは列位置を使うが、確定後のフィルタ・ソート・集計・置換・出力列は`columnBindings`に列IDを記録し、実行時に解決する。名前・順序を変えても同じ列を参照する。型変換は入力の列IDを引き継ぐ。接続先を変更した場合や対象列を設定し直した場合は再び結び付ける。

- 整数のフィルタ・ソート・SUM・最小値・最大値は整数で処理する。集計の中間値はi128、結果はi64の範囲を検査する。
- 整数の平均が整数にならない場合はエラー。小数への自動変換や丸めは行わない。
- 整数・真偽値列のソートは列型に従う（比較方法の切り替えは文字列列のみ）。真偽値の順序はfalse→true。nullは昇順・降順とも末尾。
- nullは通常の比較・IN／NOT INの対象外。集計ではnullだけを除外し、COUNTは行数。最小値・最大値・平均の対象がすべてnullならエラー、SUMは0。
- UNIONは列名・列数・順序に加え型とnull許容の一致が必要。列IDは最初の入力を引き継ぐ。
- 置換は文字列列が対象。nullは保持する。
- JSON・CSV・テキスト入力は自動的な型推定をせず、必要な列を型変換ノードで指定する。
- 文字列だけの表の従来の数値比較・集計は維持する。型付き表の数値集計には整数列を指定する。従来の文字列数値処理と整数列の厳密な計算は区別する。

列の挿入・削除には従来の接続先制約が残る。列の並べ替えは、手動更新や集計・スクリプトの接続中でも可能。スクリプトの前回結果の列位置は変更しない。行は引き続き位置参照。

## 保存・MCP・外部スクリプト

保存形式はバージョン3。旧形式の移行は行わず、非対応ファイルは読み込みを拒否する。既存の自動保存ファイルを削除・初期化・上書きして新形式へ変換しない。

共通操作は`setColumnType`、`setTypeConversion`。MCPでも同じ操作を使う。前者は`columnId`・`config`・`expectedConfig`を指定する。後者は`columns`と、競合検出用の任意の`expectedColumns`を指定する（GUIは必ず付ける）。MCPの`get_node`は原文／表示文字列の`rows`に加え`columnSchema`・`cellErrors`・最新結果の`typedRows`を返す。長い文字列本文は従来のサイズ制限付き`rows`だけで返し、`typedRows`の文字列セルには型だけを載せる。

型付きJSONLは[外部スクリプト](external-scripts.md#型付きjsonlバージョン2)を参照。

## 検証

整数の境界値、空欄規則とnull許容の独立性、原文保持、失敗時の成功キャッシュ保持、後続伝播、手動更新、Undo／Redo、列名・列順変更、保存復元、型付きJSONLのlist／dict、実プロセスの不正出力、MCPとGUI用APIの同一状態を自動検証する。実IME候補選択・再変換は手動確認対象として残る。

2026-11-25の実画面確認（独立したポート・保存先）では、整数型の適用、空欄初期値0、null許容と空欄規則の独立切り替え、型エラーの原文・表示、90%ズームでの複数行貼り付けとエラー回復、型変換ノードの追加・接続・null非許容による失敗と許容後の回復を確認した。日本語の文字入力は行ったが、実IME候補選択・再変換は未確認。
