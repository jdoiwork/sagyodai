# 置換ノード

ツールバーの「置換」で追加し、入力元・対象列・方法・検索文字列・置換後の文字列を設定して「置換を適用」を押す。各行の指定列を加工し、元の表・行数・他の列を変えずに出力する。結果を見るには結果表へ接続する。複数列や複数段階の加工はノードを直列に接続する。

- 「結果を新しい列に追加」がオフなら対象列を置換し、オンなら元の列を残して表の末尾に結果列を追加する。列名は入力でき、空欄・空白のみなら「置換（元の列名）」。同名の列がある場合は「 (2)」などを付ける。指定列名は240文字以内、列数は50列まで。
- 文字列置換: 大小文字を区別し、各セルの一致箇所をすべて置換する。記号や `$` はそのまま扱う。
- 正規表現置換: Rustの[regex](https://docs.rs/regex/latest/regex/struct.Regex.html#method.replace_all)の構文を使用する。置換文字列の `${1}`・`${name}` は捕捉グループ、`$$` はドル記号。存在しないグループは空文字になる。先読み・後読み・パターン内の後方参照は未対応。`(?i)` で大小文字の区別を無効にできる。
- 置換後が空なら一致部分を削除する。検索文字列が空の場合は適用できない。正規表現の `^` など、長さ0の一致は使用できる。
- 検索・置換文字列は各1000バイト、出力セルは100000バイトまで。不正な正規表現、対象列の欠落、出力上限超過ではノードにエラーを表示し、前回成功した出力を保持する。条件を修正して再適用できる。
- 編集中は「未適用」を表示する。適用済み設定はプロジェクトに保存し、Undo／Redo・別タブ同期に対応する。
- デフォルトで自動更新。手動更新では条件変更や上流の変更を更新待ちにし、「今すぐ更新」で実行する。

任意の式やスクリプトを実行する汎用mapノードは未実装。初期の行ごとの加工として置換だけを扱う。
