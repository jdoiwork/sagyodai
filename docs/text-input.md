# テキストファイル入力

「入力を追加」→「テキスト」で追加し、「ファイルを選択」からUTF-8のテキストファイルを読み込む。拡張子は限定しない。出力端子からフィルタ・置換・集計・結果表などに接続できる。

- 画面はメモと同じ本文中心の閲覧表示。「Markdown」「テキスト」ボタンで切り替えられる。テキスト表示は記号・改行・空白をそのまま表示し、出力には影響しない。表示形式はそのタブ内の一時設定で、ページを開き直すとMarkdownに戻る。本文の直接編集は行わず、ファイル選択で更新する。出力は「本文」という1列の読み取り専用表となる。LFまたはCRLFの改行ごとに1行となる。
- 先頭のUTF-8 BOMは除去する。空行・末尾改行による空行・前後の空白は保持し、空ファイルは空文字列1行になる。メモと同じ行分割規則。
- 最大1 MiB、5000行（空行を含む）、1行100000バイト。UTF-8以外や上限超過はノード内にエラーを表示する。
- ファイル名と読み込んだ原文・出力をプロジェクトに保存し、自動保存からの復元にも対応する。絶対パスは保存しない。
- 「ファイルを選び直す」で再読み込みできる。失敗時は前回の原文と出力を維持する。成功時は後続の自動ノードを更新し、手動ノードは前回結果を保持する。Undo / Redoも可能。
- 新規作成時のサイズもメモと同じ。表示用の表が必要な場合は結果表へ接続する。

ファイルの変更監視、自動再読み込み、文字コードの自動判別や選択は未実装。
