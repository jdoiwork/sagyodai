# シートとシート間参照

画面下の「＋ シート」で空のシートを追加し、タブでキャンバスを切り替える。シート名はタブをダブルクリックして編集する。新規ノードは表示中のシートに所属する。

- シートは表示上の区分。ノードID・依存関係・計算・キャッシュはプロジェクト全体で共有する。
- フィルタ・結果表の「入力元」、結合の「入力を追加」では、全シートのノードを「シート名 / ノード名」で選べる。循環接続はシートをまたぐ場合も拒否する。
- 同じシート内の接続は従来どおり線で表示する。別シートからの入力は端子に入力元のシート名・ノード名を表示する。シートをまたぐ接続は入力元の選択欄で設定する。
- 別シートへの切り替えは計算を停止しない。自動更新・手動更新・失敗時のキャッシュ保持は同じ規則を使う。
- シート一覧・名前・ノードの所属は共通操作API経由で変更し、自動保存・ファイル保存・別タブ同期・共通Undo／Redoの対象とする。
- 閲覧中のシートと各シートのパン・ズームはブラウザタブごとの一時状態。別タブの閲覧位置を動かさず、切り替えではUndoを増やさない。ページの再読み込みでは初期表示に戻る。
- 非表示のノードは入力途中のUI状態を保持する。セルは通常どおりフォーカス移動時に確定し、未適用のフィルタ条件は切り替え後も残る。

現段階は最大20シート、ノードは全シート合計20個。シートの削除・並べ替え・既存ノードの別シートへの移動は未実装。

## 保存データ

プロジェクトに `sheets`（安定したIDと名前）、各ノードに `sheetId` を持つ。これらが未指定の場合は「シート 1」を初期値にする。存在しない所属シート、空・重複ID、不正な名前を拒否する。プロジェクト形式のバージョンは2を維持する。

## 検証

自動テストで、別シートの参照・自動更新・手動更新と実行・キャッシュの保存復元、シート作成のUndo／Redo、不正な所属の拒否と状態維持、シート名の入力検証を確認する。

実画面でシート追加、表示切り替え、別シートの表を入力にした結果表示、セル確定直後のシート切り替えと結果更新、シートごとのズーム復帰、空の名前のエラーと修正後の適用を確認した。別タブで異なるシートを閲覧したままの更新同期、未適用条件の保持、サーバー再起動後のシート・参照・結果の復元も確認した。日本語IMEの実際の候補選択は別途手動確認が必要。
