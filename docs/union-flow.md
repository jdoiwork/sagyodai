# UNION / UNION ALL

ツールバーの「結合」でノードを追加する。初期値は **UNION ALL**。結合ノードの「＋ 入力」端子へ複数の出力をドラッグするか、「入力を追加」から表を選ぶ。結合ノードの出力は、フィルタ・別の結合・結果表へ接続できる。

- **UNION ALL**: 入力一覧の順に全行を連結する。重複を残す。
- **UNION**: 同じ順に連結し、全列の文字列が一致する行を最初の1行だけ残す。入力内の重複も除く。
- 入力一覧の↑／↓で順序を変更する。×または線の右クリックメニューで、その入力だけを解除する。
- 列名・列数・並びが完全一致する表を対象にする。列名による自動並べ替え・型変換は行わない。
- 現在の表は文字列なので、例えば「1」と「1.0」は別の値。空行も通常の行として扱う。条件のORと行の重複処理は異なる。
- 同じ接続元は1回だけ追加できる。最大19入力（プロジェクト全体は100ノード）。入力なしは未接続エラー、1入力から実行可能。結果は5000行まで。
- 手入力の表・フィルタ・結合・ソート・集計・結果表を入力にできる。結果表の出力列設定も結合入力へ反映する。

自動／手動更新、成功時キャッシュ、コンパクト表示、Undo／Redo、別タブ同期、保存・復元に対応する。列の不一致、上流の更新待ち・エラー、行数上限超過では前回成功した結果を消さず、エラーと更新待ちを表示する。循環する接続と存在しない入力は操作自体を拒否する。

接続済みの入力は、それぞれ番号と入力元名の付いた専用端子に表示する。番号は入力一覧と対応し、並べ替え後も線は同じ入力元につながる。追加は「＋ 入力」端子を使う。コンパクト表示でも全端子を表示できる高さを確保する。

接続線は入力ごとに色を保存し、専用端子の右クリックでもその入力の色を変更できる。端子からドラッグした場合は開始端子の色を引き継ぐ。結合の入力線は、線の端を付け替える代わりに解除して新しい入力を接続する。入力一覧の並べ替えでは線の色も維持する。

## 列構成の編集

結合へつながる上流表の列を途中に挿入・削除・並べ替えする場合は、結合の入力接続を外してから行う。独立した複数の入力と、その先のフィルタ・フッターの列参照を、片方の表だけの操作で誤って変更しないための現段階の制限。末尾への列追加や列名変更で入力間に不一致ができた場合は、結合にエラーを表示し、列構成が一致すると再計算する。

## 検証

実画面で2本の線をドラッグ接続し、同じ3行を持つ2表についてUNION ALLが6件、UNIONが3件になること、入力順変更、結果表への出力、右クリックで1本だけ解除、Undoによる復元を確認した。

専用端子の表示、入力順変更後の線の追従、コンパクト表示、端子の色変更、「＋ 入力」へのドラッグによる再接続を実画面で確認した。

自動テストでは全入力端子が収まるノード寸法、順序と重複排除、完全一致する文字列比較、0行、行数上限、列不一致と復旧、手動更新とキャッシュ保持、循環・重複入力・存在しない入力の拒否、保存復元、入力削除と色の維持を確認する。
