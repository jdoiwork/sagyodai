# 結果表の出力列

結果表の「出力列の設定」を開き、列をチェックで選択し、上下ボタンで順序を変更する。入力欄で出力列名を指定でき、空欄・空白のみなら入力列名を使う。結果表の列ヘッダー（A・Bなどの文字部分も含む）をドラッグして順序を変えることもできる。ヘッダーのドラッグはその場で確定し、非表示列と指定名を保って出力列設定を更新する。更新待ち・エラー中はヘッダードラッグを無効にし、手動ノードでは更新後に結果へ反映する。設定欄では「出力列を適用」で結果表のデータを更新し、後続ノードにも反映する。チェックを外した列は設定欄に残り、再選択できる。「入力列に戻す」を適用すると、すべての入力列を元の順・名前で出力する。

- 出力は最低1列。指定名は240文字以内。出力列名の重複は適用前にエラー表示する。
- セル値は読み取り専用で、入力元の表は変更しない。
- 結果表にも出力端子を設け、フィルタ・集計・結合・別の結果表へ接続できる。循環接続は拒否する。
- クイック検索・列の値による絞り込み・表示ソートは従来どおり表示だけに作用する。出力列設定を適用すると、古い列位置に対する表示設定は解除する。
- 自動／手動更新、最後に成功した出力の保持、共通Undo／Redo、別タブ同期、プロジェクト保存・復元を利用する。未適用の編集は保存対象外。
- 入力列の構成が変わった場合はエラーとして前回出力を保持する。「入力列に戻す」から設定し直す。列位置を誤って参照しないため、出力列設定済みの結果表へ接続中の上流では列挿入・削除・並べ替えを拒否する（集計ノードと同様）。接続を外して変更後、再接続して設定し直す。
- 結果表の出力列構成を変えた場合、後続ノードで指定した列の条件も確認する。列の意味を追跡する安定IDによる参照はまだ未実装。

検証: 自動テストで列選択・順序・名前・入力不変、結果表同士の接続と伝播、循環拒否、保存復元、Undo／Redo、手動更新、入力列構成変更時のキャッシュ保持、重複名や全列非表示の編集時エラーを確認する。

実画面で列の非表示・上下移動・日本語の別名を適用し、結果表の列と値が変わることを確認。APIで接続した別の結果表にも同じ6列・全行が渡ることを確認した。IME候補選択の実操作は未検証。

ヘッダードラッグの検証: 80%ズームの実画面でAの文字部分から列を移動し、接続先の結果表にも列順と値が反映されることを確認。自動テストで非表示列・別名の保持、保存復元、Undo、古い列構成での操作拒否を確認した。

結果表の列名は列ヘッダーの名前をダブルクリックしても編集できる。Enterまたはフォーカス移動で確定し、Escapeで取り消す。空欄・重複名・240文字超過は編集欄にエラーを表示する。確定した名前は出力列設定と後続ノードへ反映する。セル値は引き続き読み取り専用。更新待ち・エラー中は列名編集を無効にする。

列名編集は80%ズームの実画面でダブルクリック、空欄エラー、修正後の確定、後続結果表への反映を確認。自動テストでは別名と入力元の不変、非表示列・並べ替え後の対象列、保存復元、Undo、古い列構成での編集拒否も確認した。IME候補選択は未検証。

結果表の列ヘッダーを右クリックし、「「列名」列を非表示」を選ぶと、その列を出力から除外する。入力原本や列の別名は残る。表示中の列ヘッダーを右クリックすると「非表示の列を再表示」に候補が並び、選んだ列を保存済みの順序・別名で戻せる。「出力列の設定」でチェックを戻す方法も使える。再表示は後続への出力にも反映し、手動ノードでは更新後に結果へ反映する。更新待ち・エラー中や、再表示すると列名が重複する場合は候補を無効にする。重複する名前は「出力列の設定」で変更する。最後の1列および更新待ち・エラー中は非表示操作を無効にする。Undoにも対応する。

右クリック非表示は80%ズームの実画面でメニューと後続結果表への反映を確認。自動テストで最後の列の保護、非表示後の別名保持・再表示、保存復元・Undo／Redo・古い列構成の拒否を確認した。

右クリック再表示は80%ズームの実画面で元の位置・別名の復元と後続結果表への反映を確認。自動テストで非表示候補の選択、他の列設定の保持、最後の表示列からの復元操作、更新待ち・重複名の無効化を確認した。

出力列の設定を開くと、ノード内を設定パネルとして使う。列一覧と説明・入力エラーはスクロール領域にまとめ、「入力列に戻す」「出力列を適用」は下部に固定する。見出しを再度押すと表に戻る。高さ240pxの結果表で一覧末尾までスクロールしても適用でき、後続の結果表にも反映されることを実画面とAPIで確認した。
