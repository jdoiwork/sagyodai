# 集計ノード

2026-11-25: [列の型](column-types.md)を追加。以下の文字列だけの表の従来仕様に加え、整数・真偽値・nullを型付きで引き継ぐ。整数の比較・集計は64ビットで正確に扱い、型エラーは後続の出力更新を止める。型付き表の数値集計、null、整数にならない平均の規則は同文書を参照。


ツールバーの「加工を追加」→「集計」から追加し、入力表 → 集計 → 結果表のように接続する。

「グループ化」でキー列を選び、「出力列を追加」で集計列を追加する。各出力列で集約関数（合計・平均・最小値・最大値・件数）、対象列、出力列名を指定する。件数は対象列なしでグループ内の全行（空欄を含む）を数える。同じ対象列・関数の集計も複数追加でき、不要な出力列はごみ箱ボタンで削除する。各出力列の「上へ」「下へ」で順序を変更できる。入れ替わる設定欄は約260msで上下に移動し、薄緑色で強調する。OSで動きを減らす設定の場合は即座に切り替える。関数・対象列・列名はまとめて移動し、「条件を適用」で確定して後続ノードへ渡す。

列名を空欄または空白だけにすると、従来どおり「合計（数量）」「件数」などを自動設定する。指定名は前後の空白を除き、240文字以内。入力エラーは適用前に表示する。

- グループのキーは文字列の完全一致。大文字小文字・空白を区別し、空文字も一つの値として扱う。複数列は値の組み合わせでまとめる。
- グループは入力で最初に現れた順に出力する。順序を変えたい場合は後ろにソートノードを接続する。
- 合計は前後の空白を除いて有限の数値として読める値だけを足す。空欄・非数値は除き、有効な値がなければ0。倍精度浮動小数点数の範囲を超える場合はエラーにして前回結果を保持する。
- グループ列なしは全行を一つに集計する。入力が0行でも合計0・件数0の1行を出す。グループ列ありで入力が0行なら出力も0行。
- 出力列はグループ列の後に、設定欄の集計列の順で並ぶ。並べ替えた順序もプロジェクトに保存する。数値集計の列名は「平均（入力列名）」など、件数列名は「件数」。重複名には連番を付け、長い出力列名は240文字までに短縮する。出力は50列以内、数値集計か件数を最低1項目必要とする。

入力原本は変更しない。自動／手動更新、成功結果のキャッシュ、失敗時の前回結果保持、Undo／Redo、別タブ同期、プロジェクト保存・復元に対応する。入力中の下書きは適用するまで保存せず、縮小中にも保持して未適用を表示する。

集計は入力と出力で列構成が変わるため、集計ノードへ接続した上流の列挿入・削除・移動は拒否する。入力接続を外して列構成を変更し、再接続後に集計対象列を設定し直す。集計条件で出力列を変更した場合も、後続ノードの対象列を確認する。

検証: 自動テストで複合キー・複数の合計・件数・空欄・0行・数値範囲超過・保存復元・手動キャッシュ・失敗時の結果保持・Undoを確認。実画面で1000行を4分類に集計し、各分類250件と合計が元データからの独立計算と一致し、結果表へ伝播することを確認した。

## 平均・最小値・最大値

数値集計は有限の数値として読めるセルだけが対象。平均の分母は有効な数値セルの数で、空欄・非数値を含むグループの行数とは異なる。最小値・最大値も数値として比較する。有効な数値がない場合、平均・最小値・最大値は空文字を出力する（合計は0）。グループなし・入力0行の場合も同じ。

計算は倍精度浮動小数点数。平均は逐次更新し、平均自体は有限でも合計が範囲超過するケースを避ける。丸め誤差はあり、固定小数点・桁数指定は未対応。選択した集計の計算が数値範囲を超えた場合はノード全体をエラーにし、前回の出力を維持する。

追加集計の検証: 自動テストで非数値の除外、有効数値がない場合、負数の最小・最大、平均計算の範囲超過回避、保存復元、各集計のみの指定を確認。実画面の4分類について、合計・平均・最小値・最大値・件数が元データからの独立計算と一致し、後続の結果表へ伝播することを確認した。

出力列設定の検証: 名前・関数・対象列・追加順・重複集計・保存復元、空欄の標準名と長すぎる名前の編集時エラーを自動テストで確認。

実画面では出力列の追加、関数・対象列の変更、日本語の列名と結果表への反映、長い列名のエラー表示と修正後の適用、80%ズームでの設定欄を確認した。IMEの候補選択操作は未検証。
