# ソートノード

ツールバーの「加工を追加」→「ソート」で追加し、入力表 → ソート → 結果表のように接続する。入力元の選択欄でも接続可能。

「ソート列を追加」で列・昇順／降順・数値／テキストを指定する。上の行から優先し、同じ値なら次の列で比較する。↑↓で優先順位を変更し、ごみ箱で条件を削除できる。変更は下書きとして保持し、「条件を適用」で出力へ反映する。列の重複指定は不可。条件なしは入力順を維持する。

- 数値: 前後の空白を除き、有限の倍精度浮動小数点数として比較する。`2` と `2.0` は同値。空欄・非数値・無限大は昇順／降順とも末尾で、互いに同値扱い。
- テキスト: 大文字小文字・空白を区別したUnicodeの文字コード順。`10` は `2` より前となる。空文字は昇順／降順とも末尾。日本語の読み仮名順・ロケール依存の照合は未対応。
- すべてのキーが同値なら元の行順を維持する。数値変換でセルの内容を書き換えない。

これは列ヘッダーの表示専用ソートとは異なり、並べ替えた行順を後続ノードへ渡す。入力原本は変更しない。デフォルトは自動更新で、手動更新・前回の成功結果の保持・Undo／Redo・別タブ同期・プロジェクト保存／復元に対応する。入力に対象列がなければエラーを表示し、前回結果を残す。

列の挿入・移動では対象列への参照を追従させる。参照中の列の削除は拒否する。既存フィルタ同様、手動更新・更新待ち・エラーの接続先がある間は列構成の変更を制限する。

コンパクト表示では適用済みの列優先順・方向・件数を表示する。入力中の条件は縮小中も保持し、未適用を示す。

検証: 自動テストで複数キー・比較方法・同値と空欄・列移動時の参照維持・保存復元・手動キャッシュ・エラー時の結果保持・Undoを確認。実画面で分類のテキスト昇順と数量の数値降順、優先順位の変更を操作し、1000行全体の出力順と後続結果表の一致を確認した。
