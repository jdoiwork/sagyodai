# 作業台 / Sagyodai

自由に配置できる表と、ノードベースのデータ処理を組み合わせるアプリです。

現在は **表編集とフィルタフローを確認する試作** です。macOS 上で、ローカルの Rust コアとブラウザ UI を起動します。

## 起動

Node.js 24 と Rust の安定版を使用します。初回は依存パッケージのダウンロードが必要です。

```sh
npm ci
npm run dev
```

[試作画面](http://127.0.0.1:5173/) を開いてください。Rust コアはポート 4318、画面は 5173 を使います。停止はターミナルで Ctrl+C。

**確定した操作はサーバーが自動保存し、起動時に復元します。** 保存先はリポジトリ内の `.sagyodai/project-4318.json`（Git対象外）です。右上の「保存」は持ち出し・バックアップ用の書き出し、「開く」はファイルの読み込みです。未確定のセル入力や未適用の条件、Undo履歴は再起動時の復元対象外です。スクリプト、MCP、Tauri のウィンドウは未実装です。

保存の範囲と制限は [プロジェクトファイル](docs/project-files.md) を参照してください。

## 試せること

- [CSVファイルの読み込み](docs/csv-input.md)と後続ノードへの出力（UTF-8）。

- 表の追加・移動・サイズ変更、キャンバスのパン・ズーム。
- 日本語を含むセル編集と Tab / Enter によるセル移動。
- タブ・改行で区切った複数セルの貼り付けと、行列の自動拡張。
- Shift＋クリックによる範囲選択、選択範囲のコピー。
- 行・列の追加、操作ボタンからの Undo / Redo。
- [別タブ間の自動同期](docs/tab-sync.md)、編集中の入力保持と競合解決。Undo はプロジェクト共通。
- [手入力の表 → フィルタ → 読み取り専用結果表](docs/filter-flow.md) の接続と自動／手動更新。
- 表・配置・接続・条件・出力キャッシュの JSON ファイルへの保存と読み込み（形式バージョン2）。

詳しい操作と確認手順は [キャンバス試作](docs/canvas-prototype.md)、製品全体の方針は [ドキュメント案内](docs/README.md) を参照してください。

## 検証

```sh
npm run check
npm run format:check
```

`check` は TypeScript の型検査、画面のビルド、Vitest、Rust のテスト、Clippy を実行します。UI の IME や操作感の確認手順は試作ドキュメントに記載しています。

シートの追加・表示切り替えと、別シートのノードの参照に対応する。詳細は[シートとシート間参照](docs/sheets.md)を参照。
