# 作業台 / Sagyodai

自由に配置できる表と、ノードベースのデータ処理を組み合わせるアプリです。

**キャンバス・表編集・データ加工の試作は一区切り** です。現在の到達点と未実装・未検証事項は [試作の振り返り](docs/prototype-review.md) にまとめています。macOS 上で、ローカルの Rust コアとブラウザ UI を起動します。

## 起動

Node.js 24 と Rust の安定版を使用します。初回は依存パッケージのダウンロードが必要です。

```sh
npm ci
npm run dev
```

[試作画面](http://127.0.0.1:5173/) を開いてください。Rust コアはポート 4318、画面は 5173 を使います。停止はターミナルで Ctrl+C。

**確定した操作はサーバーが自動保存し、起動時に復元します。** .env.local の設定や環境変数で変更しない場合、保存先はリポジトリ内の `.sagyodai/project-4318.json`（Git対象外）です。右上の「保存」は持ち出し・バックアップ用の書き出し、「開く」はファイルの読み込みです。未確定のセル入力や未適用の条件、Undo履歴は再起動時の復元対象外です。Tauri のウィンドウは未実装です。[外部スクリプト](docs/external-scripts.md)で文字列表を別プロセスのPythonなどに渡せます。MCPからの基本操作は[接続手順](docs/mcp.md)を参照してください。

保存の範囲と制限は [プロジェクトファイル](docs/project-files.md) を参照してください。

## MCP接続

起動中のコアに、stdioのMCPアダプタを接続できます。手入力表・フィルタ・結果表の作成、接続、編集、実行、結果取得に対応します。GUIと同じ状態・Undo・自動保存を使います。ビルドとクライアント設定は [MCP操作](docs/mcp.md) を参照してください。

## 検証

```sh
npm run check
npm run format:check
```

`check` は TypeScript の型検査、画面のビルド、Vitest、Rust のテスト、Clippy、MCPの実stdio接続テストを実行します。スクリプトの検証には `/usr/bin/python3` のPython 3も必要です。UI の IME や操作感の確認手順は試作ドキュメントに記載しています。

シートの追加・表示切り替えと、別シートのノードの参照に対応する。詳細は[シートとシート間参照](docs/sheets.md)を参照。
